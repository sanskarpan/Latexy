# Latexy homepage font subsets

Latexy Display derives from the Hubot Sans project by GitHub and its contributors.
Latexy Reading derives from the Mona Sans project by GitHub and its contributors.
Both derivatives remain under SIL OFL 1.1. The original copyright and licence
notices are included unchanged in HubotSans-OFL.txt and MonaSans-OFL.txt.

2026-10-17:
- Subset to Latin, extended Latin and common punctuation for homepage copy.
- Instantiate display weight 600, width 95; reading weights 400/500/600, optical size 20.
- Set other axes to their upstream defaults and retain WOFF2 compression.
- Rename family, style, full, unique and PostScript identifiers to Latexy Display
  and Latexy Reading, respecting the upstream reserved names. These are modified
  web subsets, not the original fonts. Glyph outlines and metrics are unaltered
  after instancing.
