## Parent controls and control plane

- Coarse parents: `compile`, `llm_optimize`, `ats_score`, `ats_deep`, `resume_builder`, `cover_letters`, `batch_tailor`, `templates`, `exports`, `ai_writing`, `macros`, `snippets`, `career_paths`, `interview_prep`, `application_tracker`, `one_click_apply`, `byok`, `collaboration`, `team_workspaces`, `portfolio`, `developer_api`, `references`, `integration_github`, `integration_dropbox`, `integration_google_drive`, `integration_zotero`, `integration_mendeley`, `ai_import_github`, `ai_import_url`, `ai_import_linkedin`, `analytics`.
- Registry is code-defined (`backend/app/core/feature_registry.py`, `capability_catalog.json`) with frozen definition objects. Admin endpoints cannot add/delete IDs or switch immutable baselines. Global, family/SKU and role cells are admin-only; account roles remain independent of document/workspace/tenant ACLs.
- `CapabilityRouter` rejects unclassified new first-party handlers at registration. Dynamic selectors cover multiplexed jobs, acceptance/source writes, format export, anonymous/share modes, role increases and setup toggles. Metadata/read/delete/revoke/cancel routes are explicitly exempted, then retain their original ACLs.
- Six operational flags are separate: `trial_limits`, `deep_analysis_trial`, `compile_timeouts`, `task_priority`, `billing`, `upgrade_ctas`. Their legacy cache/fail-open semantics do not authorize product capabilities. Verify deployed configuration and operator semantics independently.
- UI entitlement context fails closed for missing/invalid maps, policy outage, identity change and stale snapshots, uses bounded refresh/expiry (30-second refresh + 8-second request timeout). Server admissions reread authoritative database, so a temporarily visible stale UI grant must still fail before new work.
- Plan/role/global mutations use expected-state concurrency checks; admin UI reconciles uncertain writes from server. Need exact deployment evidence for non-admin denial, immutable baseline rejection, concurrent-tab writes, restoring accidental disable and legacy endpoint compatibility.
